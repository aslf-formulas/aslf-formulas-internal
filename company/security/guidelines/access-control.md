# Access Control

*Last updated: March 2026*

---

## Overview

ASLF Formulas operates primarily through AI agents, automated tools, and third-party platforms. This document defines how access is granted, managed, and revoked for both AI systems and any human collaborators.

---

## Principles

1. **Least Privilege** — Every AI agent and system is granted only the minimum access required for its function
2. **Separation of Concerns** — No single AI agent has unrestricted access to all systems
3. **Owner Override** — The owner holds master access to all systems and can revoke any agent's access immediately
4. **Auditability** — All access and actions taken by AI agents must be logged and reviewable

---

## Access Tiers

| Tier | Who / What | Access Level |
|---|---|---|
| **Owner** | Human owner of ASLF LLC | Full admin access to all systems |
| **Autonomous AI Agents** | Claude, Make.com automations, Klaviyo, Shopify apps | Scoped API access — read/write within defined scope only |
| **Read-Only AI Agents** | Reporting tools, analytics agents | Read-only access to data sources |
| **Vendors / Contractors** | Any external party | Time-limited, scoped access only; revoked upon completion |

---

## API Key Management

All AI agent integrations use API keys or OAuth tokens. The following rules apply:

- API keys are **never hard-coded** in any public repository
- All API keys are stored in a **password manager** (e.g., 1Password) or secrets manager
- Each integration uses its **own dedicated API key** — keys are not shared across services
- API keys are rotated **every 90 days** or immediately upon suspected compromise
- Unused or expired integrations have their API keys **revoked immediately**

### Key Inventory (maintain in password manager)

| System | Key Type | Rotation Schedule | Owner |
|---|---|---|---|
| Shopify (admin API) | API key + secret | 90 days | Owner |
| Klaviyo | Private API key | 90 days | Owner |
| Meta Ads | Access token | On expiry | Owner |
| Google Ads | OAuth token | On expiry | Owner |
| AI agent (e.g., Claude API) | API key | 90 days | Owner |
| Shipping carrier | API key | 90 days | Owner |

---

## Password & Account Security

- All accounts use **unique, strong passwords** generated by the password manager
- **Two-factor authentication (2FA)** is mandatory on all accounts, including:
  - Shopify
  - Klaviyo
  - Email (Google Workspace)
  - Financial accounts
  - Domain registrar
  - Hosting / CDN
- Recovery codes are stored securely in the password manager

---

## Access Revocation

When removing access for any agent, tool, or contractor:

1. Revoke API key or OAuth token in the respective platform
2. Remove from password manager vault (if applicable)
3. Confirm access is removed by attempting to authenticate with the old credentials
4. Log the revocation with date and reason
