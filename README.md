## Who We Are (read this first)

> *ASLF Formulas is the work of a longevity analyst who cares about the field
> so much that he built a clean product line he'd actually trust. The editorial
> mission leads; the products exist because of it, not the other way around.*

We are an **editorial mission that happens to have built products** — not a
brand that happens to make content. The single source of truth for this
identity is [company-guidelines/positioning.md](./company-guidelines/positioning.md),
which every content and strategy agent references so all output pulls in the
same direction.

---

## A Blueprint for the Autonomous Company

This repository is also a **working blueprint for how to run a company using
primarily AI agents and automation**. The principle: if a human has to do it
repeatedly, a system should do it instead. AI agents handle digital operations;
robotic systems and 3PL handle physical operations. The owner's role is to set
*editorial direction* and strategy, review outputs, and make key decisions —
not to operate the business day-to-day.

The two ideas work together: the **autonomous-company model is how we operate**;
the **longevity-analyst mission is why we exist**.

## How to Use This Repo

- **Start every session** by loading the orientation files (see
  [tasks/](./tasks/)) and the positioning source of truth.
- **Reading docs:** open the relevant folder's markdown file.
- **Adding documents:** follow the `kebab-case.md` convention and update the
  folder `README.md`.
- **Deploying a new AI agent:** follow [operations/onboarding.md](./operations/onboarding.md)
  and reference positioning.md so the agent acts consistently with the mission.
