## A Blueprint for the Autonomous Company

This repository is more than an internal wiki — it is a **working blueprint for how to run a company successfully using only AI agents and robots**.

Every document in this repository is written with one principle: **if a human has to do it repeatedly, a system should do it instead.** AI agents handle all digital operations. Robotic systems handle all physical operations. The owner's role is to set direction, review outputs, and make strategic decisions — not to operate the business day-to-day.

ASLF Formulas is a proof of concept that a lean, solo-founded consumer brand can compete at scale by replacing operational overhead with intelligent systems. This repo documents how.

## How to Use This Repo

- **Reading docs:** Navigate to the relevant folder and open the markdown file.
- **Updating docs:** Always create a new branch and submit a pull request before merging to `main`.
- **Adding new documents:** Follow the existing naming convention (`kebab-case.md`) and update the folder `README.md`.
- **Deploying a new AI agent:** Follow the checklist in [operations/onboarding.md](./operations/onboarding.md).
