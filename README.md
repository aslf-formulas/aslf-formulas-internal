## A Blueprint for the Autonomous Solo Founder

This repository is a **working blueprint for running a company and a life using AI agents and automated systems.**

ASLF Formulas is solo-founded and intentionally designed to stay that way. Every repeated task is a candidate for automation. Every decision that can be delegated to an AI should be. The owner's role is to set direction, review outputs, and make strategic decisions — not to operate anything day-to-day.

This repo covers both domains: the **company** and the **person running it.** They share the same time and energy budget, so they are planned and optimized together.
