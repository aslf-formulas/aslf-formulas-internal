# YouTube Thumbnail Process

*Last updated: March 2026*

---

## Overview

Thumbnails are generated automatically by AI agent (Claude via Canva MCP) based on video titles pulled from Notion. The owner reviews the generated options and selects the preferred concept. This is triggered each time a new video is finished.

## Step-by-Step Process

### Step 1 — Identify the Latest Finished Video
1. AI agent opens the Notion **VIDEO IDEAS** board (read-only)
2. Locates the **FINISHED VIDEOS** section
3. Identifies the most recent video (highest number)
4. Copies the title for use in thumbnail concepts

> Current last finished video: **18 - Electrolytes are a SCAM??**

---

### Step 2 — Draft 3 Thumbnail Concepts

For each video, always create **3 distinct thumbnail concepts** targeting different psychological hooks:

| Concept Type | Hook | Example |
|---|---|---|
| **Myth Buster** | Confrontational, provocative | "ARE ELECTROLYTES A SCAM?" + bold graphic |
| **Money / Value** | Loss aversion, waste | "STOP WASTING MONEY" + dollar signs |
| **Science / Truth** | Authority, credibility | "WHAT STUDIES ACTUALLY SAY" + clean layout |

---

### Step 3 — Generate in Canva

1. AI agent generates the 3 concepts via **Canva MCP integration** — creates a new presentation with 3 slides
2. AI agent presents options to owner for review
3. Owner selects preferred concept
4. Owner (or AI agent) copies selected slide into the main **YT Thumbnails** project (DAF5V-ELcU0)

> **Rules:**
> - Notion: **read-only** — never modify
> - Canva: **create-only** — never delete or overwrite existing slides

---

### Step 4 — Finalize in Canva

- Adjust colors to match brand palette if needed
- Ensure text is readable at small sizes (mobile preview)
- Use brand graphics, product photography, or AI-generated imagery
- Export as JPG at 1280x720px

---

## Thumbnail Best Practices

| Element | Guideline |
|---|---|
| **Size** | 1280 x 720 px (16:9) |
| **File format** | JPG or PNG, max 2MB |
| **Text** | Max 6–8 words, large and bold |
| **Imagery** | Brand visuals, product shots, or AI-generated graphics |
| **Colors** | High contrast — avoid dark on dark |
| **Brand** | Consistent with channel visual identity |
| **CTR hook** | Every thumbnail should create curiosity or urgency |
