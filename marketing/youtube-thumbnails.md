## Overview

This document defines the standard process for creating YouTube thumbnail drafts for ASLF Formulas videos. Thumbnails are created in Canva using concepts pulled from the active video list in Notion.

## Step-by-Step Process

### Step 1 — Identify the Latest Finished Video
1. Open the Notion **VIDEO IDEAS** board (read-only)
2. Locate the **FINISHED VIDEOS** section
3. Note the most recent video at the bottom of the list (highest number)
4. Copy the video title for use in the thumbnail concept

> Current last finished video: **18 - Electrolytes are a SCAM??**

---

### Step 2 — Draft 3 Thumbnail Concepts

For each video, always create **3 distinct thumbnail concepts** targeting different psychological hooks:

| Concept Type | Hook | Example |
|---|---|---|
| **Myth Buster** | Confrontational, provocative | "ARE ELECTROLYTES A SCAM?" + shocked face |
| **Money / Value** | Loss aversion, waste | "STOP WASTING MONEY" + dollar signs |
| **Science / Truth** | Authority, credibility | "WHAT STUDIES ACTUALLY SAY" + clean layout |

---

### Step 3 — Generate in Canva

1. Ask Claude to generate the 3 thumbnail concepts as a new Canva design
2. Claude will use the **Canva MCP integration** to create a new presentation with 3 slides
3. Review the generated options (Claude will present multiple style variants)
4. Open your preferred option in Canva
5. Manually copy the slides into the main **YT Thumbnails** project (DAF5V-ELcU0)

> **Rules:**
> - Notion: **read-only** — never modify
> - Canva: **create-only** — never delete or overwrite existing slides

---

### Step 4 — Refine in Canva

Once copied into the main project:
- Add your face/photo if the concept calls for it
- Adjust colors to match your brand palette
- Ensure text is readable at small sizes (mobile preview)
- Export as JPG at 1280x720px

---

## Thumbnail Best Practices

| Element | Guideline |
|---|---|
| **Size** | 1280 x 720 px (16:9) |
| **File format** | JPG or PNG, max 2MB |
| **Text** | Max 6–8 words, large and bold |
| **Faces** | Use close-up facial expressions when possible |
| **Colors** | High contrast — avoid dark on dark |
| **Brand** | Keep consistent with channel visual identity |
| **CTR hook** | Every thumbnail should create curiosity or urgency |
