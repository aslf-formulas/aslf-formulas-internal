# Marketing skills

Paste/reference recipes for Grok Bot and human editors. They live in git next to `video-editing-guidelines.md`.

These are **not** agent system prompts. Keep each skill generic (reusable across videos), not a one-off cut list.

Grok Bot may also keep a live copy of a skill as a private skill; this folder is the durable shared source.

Pack mode includes `imagine-agent-batch.md` (one paste to Grok Imagine) plus Markdown checklists for VS Code.
