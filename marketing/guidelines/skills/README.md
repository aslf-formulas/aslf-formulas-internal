# Marketing skills

Paste/reference recipes for Grok Bot and human editors. They live in git next to `video-editing-guidelines.md`.

These are **not** agent system prompts. Keep each skill generic (reusable across videos), not a one-off cut list.

Grok Bot may also keep a live copy of a skill as a private skill; this folder is the durable shared source.

## Pack mode (default)

One path for **long-form** and **weekly longevity news Shorts**: [`premiere-pack`](premiere-pack/SKILL.md).

- One `premiere-pack.md` event timeline (not beat-by-beat). No separate `checklist.md` / `checklist.csv`.
- One `imagine-agent-batch.md` paste to Grok Imagine for **all** stills, including graphs/charts/stat plots, plus style-ref.
- **Style-only reference:** attached refs (e.g. `style-ref-follicle-abs201.jpg`) lock look/palette/lighting/texture — never the depicted subject. Batch header: “STYLE REFERENCE ONLY — match look; do not depict the reference subject unless the brief asks for that subject.”
- **Still → motion:** when a still should move, copy [`imagine-still-to-motion`](imagine-still-to-motion/SKILL.md) into `animation-prompt.md` or a section of the Imagine batch — not an ad-hoc prompt.
- Premiere may only add title/chip text on top of Imagine graph stills.

News Shorts: same Pack. Vertical timeline, hard 3:00 cap, center captions, 1:1 explainers, graphics stack from `video-editing-guidelines.md`. Briefing is the week’s news items plus which graphs/images to generate, in one Imagine pass.

[`long-form-premiere-pack`](long-form-premiere-pack/SKILL.md) redirects here (old name).
