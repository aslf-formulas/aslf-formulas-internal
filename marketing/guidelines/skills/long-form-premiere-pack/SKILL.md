# Long-form Premiere pack (Pack mode)

## When
Philipp (or Social Media Manager) provides a long-form transcript JSON/SRT and wants Pack mode (default). Do **not** run beat-by-beat “next” unless he asks for co-edit.

## Inputs
- Transcript path (Premiere JSON preferred)
- Standing guidelines: `marketing/guidelines/video-editing-guidelines.md` (local copy often under `/workspace/video-editing-guidelines.md`)
- Imagine style: bright clinical journal-figure (ABS-201 follicle look); project **Video Editor Graphs**
- Ask Content Researcher for cleared study snapshot URLs early

## Deliverables (one folder under `/workspace/<slug>/`)
1. `premiere-pack.md` — full HOOK (heavy first ~2–3 min) / BODY (meaning-driven) / CLOSE; ASR table; Stock checklist; snapshot URLs; soft absolute language
2. `checklist.csv` — timestamp, type, on_screen_text, asset_notes (burn top→bottom)
3. `imagine-briefs.md` — paste-ready Imagine agent prompts (1:1 or 16:9 as noted)
4. `as-recorded.md` — topics, runtime, ASR notes, named citations
5. `snapshot-urls.md` — Researcher-cleared URLs

## Rules
- No planned zooms; captions assumed done
- Disclaimer ≥2s prefer ≥3s + Research news / Not medical advice in first 10s
- Skip redundant punchlines; Premiere owns numbers/keywords; Imagine owns process/mechanism
- Wire Researcher URLs before calling the pack “done”
- Deliver a short TLDR in chat + paths; he places in Premiere and pings only for Imagine taste / sticky beats

## After
- Offer GitHub log under `marketing/scripts/long-format/` (or series folder)
- Ping Social Media Manager when posting-ready (approval-first)
